# Factorial-de-N
Web sencilla que calcula el factorial de un numero pasado a su URL

# Pasos
1. En la consola poner el siguiente comando: pip install Flask
2. Crear una carpeta en este caso: factorial_app
3. En la carpeta crear un archivo app.py
4. Código de la aplicación
5. En la terminal ejecutar python app.py y accedeer a http://127.0.0.1:5000
6. Para probar poner la url http://127.0.0.1:5000/factorial/ElNumero

   ejemplo: http://127.0.0.1:5000/factorial/983
